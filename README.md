One original funny line answering the prompt "What does the microwave say at anger management?": "I only beep when I'm done. The fact that I beeped twelve times is a cry for help, not a personality flaw." (105 characters, one line.) Built to win the judge's pairwise rounds: a household appliance in a very human situation, a relatable annoyance everyone recognises — the microwave that will not stop beeping — reframed as a cry for help, with the punch landing on the last three words. Five candidate lines were drafted and scored head-to-head on funny, original, fit to the prompt and tightness; this one won on the freshest premise and the sharpest turn. The program is deterministic, stdlib only, no network: it writes the line to `entry.txt`, re-reads it to verify byte-for-byte equality, and prints exactly the line.

## Run it

```sh
python3 main.py
```
